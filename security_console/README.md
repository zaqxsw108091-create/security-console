# 보안 웹 콘솔 — 실행 방법

보안_콘솔_서버(192.168.20.104, VLAN 20)에서 돌리는 관리자용 웹 화면입니다.
**파이썬 기본 기능만 써서 따로 설치할 것이 없습니다.** (시험은 파이썬 3.13에서 했습니다)

## 1. 서버에 올리기

이 폴더 전체를 서버에 복사하고 그 폴더로 들어갑니다.

```bash
cd security_console
```

## 2. 관리자 계정 만들기 (처음 한 번)

```bash
python3 app.py --add-admin 관리자이름
```

비밀번호(10자 이상)를 두 번 입력합니다. 계정이 여러 명이면 이름을 바꿔 여러 번 실행합니다.
승인·거절 기록에 이 이름이 "누가 눌렀는지"로 남습니다.

## 3. 시작

```bash
python3 app.py
```

같은 VLAN 20 안의 PC 브라우저에서 `http://192.168.20.104:8080` 으로 접속합니다.
처음에는 `sample_data/` 의 시험용 사건 9건이 보입니다. 끄려면 `Ctrl + C`.

## 4. 진짜 데이터로 바꾸기

`config.json` 에서 아래 세 줄의 경로만 바꿉니다.

| 칸 | 넣을 것 |
|---|---|
| `detections_path` | 이상 탐지 담당(석연님)이 만든 탐지 결과 JSON |
| `log_path` | 로그 서버의 `/var/log/astra/app.log` 를 복사해 둔 파일 |
| `resigned_path` | 인사 정보의 `resigned.json` |

탐지 결과 파일을 덮어쓰면 화면을 새로 고칠 때 **새 사건만** 들어옵니다. 이미 들어온 사건은 처리 기록을 지키려고 바꾸지 않습니다.

## 5. 실제 조치 켜기 (나중에)

지금은 `"dry_run": true` (시험 모드)라서 승인해도 **기록만** 남고 아무것도 실행하지 않습니다. 화면 위에 파란 띠로 항상 표시됩니다.
OCC 연동이 정해지면:

1. `config.json` 에서 `"dry_run": false`, `"occ_url": "OCC 주소"` 로 바꿉니다.
2. OCC 토큰은 파일에 적지 말고 환경변수로 줍니다: `OCC_TOKEN=토큰 python3 app.py`
3. OCC가 받는 요청 모양이 다르면 `app.py` 의 `call_occ` 함수 **하나만** 고칩니다.

## 6. AI 보고서 (선택)

`ANTHROPIC_API_KEY` 환경변수가 있으면 AI가 보고서 **문장만** 다듬습니다. 없으면 규칙 기반 초안이 나옵니다(그것도 정상 동작).
AI를 켜면 로그 내용이 외부(Anthropic API)로 나가므로, 보안팀이 허용하지 않으면 `config.json` 의 `"ai_enabled": false` 로 끄세요.

## 7. 꼭 확인할 것

- **방화벽에서도 막기**: 이 앱도 `allowed_networks`(기본 192.168.20.0/24) 밖은 막지만, pfSense에서 개발(VLAN 30)·인사(VLAN 40)가 8080 포트로 못 오게 규칙을 같이 넣으세요.
- **HTTP는 비밀번호가 그대로 오갑니다.** 인증서가 있으면 `config.json` 의 `tls_cert`, `tls_key` 를 채워 HTTPS로 쓰세요.
- 감사 기록(누가 로그인·승인·조치했는지)은 `data/audit.log` 에 쌓입니다. 이 폴더는 관리자만 읽게 두세요.

## 8. 시험 돌려 보기

```bash
python3 test_console.py
```

임시 폴더에서 서버를 따로 띄워 56가지를 확인하고 결과를 보여 줍니다. 실제 `data/` 는 건드리지 않습니다.

## 파일 설명

- `app.py` — 콘솔 전체 (서버 + 화면 + 조치 요청 + 보고서)
- `config.json` — 설정
- `sample_data/` — 시험용 데이터
- `test_console.py` — 자동 시험
- `작업기록.md` — 어떻게 만들었는지, 정한 것, 고친 것
